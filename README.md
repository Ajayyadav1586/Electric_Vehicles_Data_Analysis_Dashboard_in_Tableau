# 🚗 Electric_Vehicles_Data_Analysis_Dashboard_in_Tablea
A comprehensive data analysis and interactive visualization project focused on electric vehicle (EV) adoption, market share by manufacturer, vehicle range metrics, and Clean Alternative Fuel Vehicle (CAFV) eligibility trends built using **Tableau** and **Python**.

---

## 📌 Project Objective

The primary objective of this project is to analyze the growth, distribution, and market performance of Electric Vehicles (EVs) using historical registration data. The insights generated aim to help automakers, policymakers, and infrastructure planners understand:
* Overall EV adoption growth across model years.
* Dominant market players (Makes & Models) driving adoption.
* Distribution between Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
* Clean Alternative Fuel Vehicle (CAFV) eligibility compliance across registered fleets.
